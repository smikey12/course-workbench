# 课藏 · 本地课程与作业工作台

首次启动为空，按需连接学习通、雨课堂、中国大学MOOC或PTA。平台读取依赖你在同一浏览器的现有登录与明确授权，原件只读，本机有报告不代表已提交。

## 下载与开始

从本仓库Code → Download ZIP取得完整源码，保留所有子目录。Windows安装Python 3.13后，双击“启动工具.cmd”或“打开课藏.pyw”，打开 http://127.0.0.1:8765/。后台启动后可关闭命令窗口。

在设置页选择平台并保存。当前未核实正式Edge Add-ons上架地址，所以首次商店安装入口未开放；源码不伪造安装按钮。已有扩展的用户保留设置页，安装/启用后以当前页nonce握手检测连接；历史缓存不能证明当前浏览器已安装。开发者模式加载仅供源码测试，不是商店安装。

授权须本人在扩展页面点击，登录须在同一浏览器完成。选中不等于已连接，需核对实际成功时间。取消平台停止该平台采集并保留旧数据。扩展只连接默认回环8765端口，其他端口可浏览记录但应回到默认入口连接。

课程资料默认data/courses/学期/课程名，下载件默认data/inbox。首次创建空目录。可在启动前设置KECANG_COURSES_ROOT和KECANG_INBOX，相对路径以工具目录为准。报告和附件关联保存原路径；解除关联不删除原件。

## 状态与排序

有真实待办的课程优先进入默认六行，同组保留学期和下拉排序。默认待完成数相同再比较已完成数、最近明确业务日期（优先发布/开放时间，其次截止时间），未知日期放后；不使用同步时间、名称或编号猜测日期。名称/开课时间手动排序保留。72小时内可提交任务标红，超过三天标橙，状态未知明确提示。

MOOC部分SPOC范围不完整，不将缺失记录当零项。PTA采用保守模式：正常最多12小时检查一次，错误从30分钟起指数退避最高12小时，预算跨扩展重启保留。单次只读当前目录或本人已打开的开放概览DOM，不翻页、不调用PTA API、不读提交/题目列表。新页有界等待导航与SPA卡片，明确空态且加载完成才接收零项；未取得结果保留缓存。实际登录跳转保留可见页面，返回同页后允许一次补读，与定时任务去重。目录缺失截止时间保留已知值，明确新日期可更新；旧核实状态保留其证据与时间，不冒充本轮成功。

## 测试和打包

```powershell
python -B -m unittest discover -v
node test_board_display.cjs
node web/test_board_platforms.cjs
node test_edge_first_install.cjs
python -B build_edge_package.py --check
python -B build_edge_package.py
```

扩展离线测试位于“雨课堂浏览器连接”的*.test.cjs；PowerShell可展开文件列表后传给node --test。测试使用模拟页面与临时库，不连接私人账号。

prepare_release.FILES是唯一源码白名单，包含必要运行文件、脱敏测试及受控原创扩展图标。build_edge_package.py只用标准库生成扩展ZIP与同源干净应用ZIP、摘要和配对清单，结果在release/，不进源码提交。现有固定白名单旧更新器不接收新增文件集合，旧用户需手动覆盖完整源码一次，保留data/数据库并重新加载扩展；不要关闭校验绕过。代码更新、公开ZIP、GitHub Release和微软上架是不同步骤，本次源码提交不创建Tag/Release或提交微软审核。

公开源码中没有商店账号或真实隐私联系。发布者须自行确认身份/支持渠道并实际托管隐私政策，见docs/privacy-template.md与docs/edge-publishing.md。正式上架后人工核对官方详情页再回填EDGE_ADDONS_DETAIL_URL，重建工作台、新摘要，并从真实下载位置独立复验首次商店安装与同步。
